# AutoResearcher

AutoResearcher is an AI-powered report generation tool that takes a topic as input and automatically creates a complete, well-structured Markdown report. It uses multiple AI agents for planning, researching, writing, editing, and presentation generation.

## Features

* Accepts any topic as input
* Breaks the topic into structured sections
* Performs automated research with facts and explanations
* Generates a complete detailed report
* Edits and improves readability automatically
* Creates an executive summary and presentation outline
* Saves the final output directly as a `.md` file

This project is useful for students, researchers, content creators, and anyone who wants to quickly generate professional reports on any topic.
